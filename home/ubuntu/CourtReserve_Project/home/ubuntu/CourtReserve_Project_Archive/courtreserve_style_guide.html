Foundations

1. Color Palette

The palette consists of two primary brand colors and neutral tones, aiming for a bright, inviting, and modern feel.

Primary Brand Colors

Vibrant Teal (Action & Energy) HEX: #00A79D
Usage: Primary buttons, active navigation, highlights.
Deep Aqua (Trust & Calm) HEX: #27677A
Usage: Secondary buttons, informational icons, subtle backgrounds.

Neutral Tones

Cloud White (Base Background) HEX: #F8F9FA
Pure White (Content Background / Cards) HEX: #FFFFFF
Charcoal Grey (Primary Text) HEX: #343A40
Medium Grey (Secondary Text / Labels) HEX: #6C757D
Light Grey (Borders / Dividers) HEX: #CED4DA

Accent & Status Colors

Forest Green (Success/Confirmation) HEX: #28A745
Amber Yellow (Warning/Pending) HEX: #FFC107
Crimson Red (Error/Decline) HEX: #DC3545

3. Typography

Primary Font Family: Inter (Fallback: Helvetica Neue, Arial, sans-serif). Weights: Regular (400), Medium (500), Semi-Bold (600), Bold (700).

Hierarchy & Sizing:

H1 / Page Titles: 28px, Bold (700), Line Height 1.2, Color #343A40

Page Title Example

H2 / Section Titles: 22px, Semi-Bold (600), Line Height 1.3, Color #343A40

Section Title Example

H3 / Card Titles: 18px, Semi-Bold (600), Line Height 1.4, Color #343A40

Card Title Example

Body Text: 16px, Regular (400), Line Height 1.6, Color #343A40

Labels / Secondary Text: 14px, Regular (400), Line Height 1.5, Color #6C757D

This is a label or secondary text.

Button Text: 16px, Medium (500) or Semi-Bold (600), Line Height 1

Caption / Small Text: 12px, Regular (400), Line Height 1.4, Color #6C757D

This is a caption or small print text.

4. Spacing and Layout Grid Principles

Base Unit: 8px. Common Spacing Values:

  • xs (Extra Small): 4px
  • sm (Small): 8px
  • md (Medium): 16px
  • lg (Large): 24px
  • xl (Extra Large): 32px
  • xxl (Extra Extra Large): 48px

Layout Grid (Mobile-First): Gutters: 16px (md) on mobile. Generous white space is encouraged.
